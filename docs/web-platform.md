# 网页版使用与兼容性 / Web guide

进入 [玄果网页版](https://aokorin.xyz/app) 后，从侧栏打开影视、漫画、分类、搜索、站源或我的。「项目主页」返回 [Huaxun233 的项目展示站](https://aokorin.xyz/)。

- **影视站源**：打开「站源 → 仓库站源」，同步配置、选择站点并批量导入。也可导入 JSON 文件、HTTPS 目录或添加视频直链。导入内容保存在当前浏览器；管理员可在独立后台发布共享片库。
- **播放**：从片库选择影片和剧集，支持浏览器可解码的 HTTPS 视频及 HLS。封面使用源站给出的图片，无法读取图片时显示标题。第三方站点的连接和线路状态会变化。
- **小果模块**：站源页可以同步客户端插件目录并查看版本和说明。目录中的原生插件由 Android 或 Windows 客户端运行。网页播放使用仓库的兼容站点、JSON 目录或视频直链。
- **漫画**：打开「漫画 → JavaScript 漫画插件」，同步内置仓库并勾选要批量安装的源。也可导入 JSON 漫画目录。网页版支持基础 VeneraX ComicSource 接口，原生图片变换、完整加密接口、验证码及完整源账号功能可能不可用。
- **我的**：可以查看视频追剧和观看记录。漫画书架和章节进度保存在浏览器，也可登录后手动上传或合并。个人影视站源随浏览器保存。

管理入口为 [独立后台](https://aokorin.xyz/admin)，使用现有管理密钥。新账号注册需要邀请码。

## English

Open the [Xghub web app](https://aokorin.xyz/app) and select **Sources** in the sidebar to batch import compatible repository catalogs, import a JSON catalog, or add a direct video URL. Personal video sources are stored in this browser. Admins can publish shared catalogs from the separate admin page.

The Guo catalog shows the client plugin descriptions and versions. Android and Windows run those native plugins. Web playback uses compatible repository catalogs, JSON or direct video URLs. Video and cover availability depends on the upstream site and browser.

In **Comics**, sync the built-in repository and batch install selected ComicSource plugins, or import a JSON comic catalog. The browser supports basic VeneraX operations. Some native image, cryptography and account APIs are unavailable. Use the account tools to manually sync your comic bookshelf and reading progress.

The **Project homepage** button opens the [Huaxun233 project showcase](https://aokorin.xyz/).
